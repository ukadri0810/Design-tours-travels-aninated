Design Tours and Travels Website

How to use:
1. Extract the ZIP file.
2. Open index.html in your browser.
3. Replace placeholder phone number +910000000000 in index.html and script.js with your real WhatsApp number.
4. Replace the address, email and Google Maps link in index.html.
5. Upload the folder to any hosting service such as Firebase Hosting, Netlify, Vercel, Hostinger, cPanel, or GitHub Pages.

Files included:
- index.html: Main website page
- style.css: Complete responsive design
- script.js: Mobile menu, package popup and WhatsApp inquiry form

Important:
The inquiry form currently sends enquiries to WhatsApp. For saving inquiries in a database, connect it to Firebase, Supabase, Google Sheets, or a backend API.
